삼척 키움지도 화면 연결

1. 압축을 풀면 kiwoom-site.html, kiwoom-review.html, data/reviews.json이 있습니다.
2. GitHub 아래 링크를 엽니다.
   https://github.com/numanjoa0422-eng/samcheok-access-check/upload/main
3. kiwoom-site.html, kiwoom-review.html 두 파일과 data 폴더를 끌어다 넣고 Commit changes를 누릅니다.
   원래 scripts/config/tests/results/data/programs.json 파일은 유지합니다.
4. 내 컴퓨터에서는 새 kiwoom-site.html을 더블클릭하면 됩니다.
   인터넷 연결이 필요하며 공개 GitHub 저장 자료를 읽습니다. 컴퓨터가 꺼져도 GitHub 수집은 계속됩니다.
   Run workflow를 새로 누를 필요는 없습니다. 화면을 열 때와 열려 있는 동안 5분마다 저장 자료를 읽습니다.

새 공고 공개

1. kiwoom-review.html을 엽니다.
2. 공고를 고르고 원문/본문 이미지/첨부를 확인합니다.
3. 일정·대상·신청방법·현재 접수 표시를 채우고 확인란 체크 → 확인 후 공개 승인.
4. reviews.json 내려받기를 누릅니다.
5. 파일 이름이 reviews (1).json 등으로 저장되면 reviews.json으로 고칩니다.
6. 아래 GitHub data 폴더에 올리고 Commit changes를 누릅니다.
   https://github.com/numanjoa0422-eng/samcheok-access-check/upload/main/data
7. 키움지도 화면에서 새로고침을 누르거나 5분 뒤 확인합니다.
   GitHub raw 파일 반영에는 잠시 지연이 있을 수 있습니다.

공개와 검토 기준

- 원문 접수기간/신청방법/대상이 불확실하면 공개하지 않습니다.
- 자동수집 status=모집중만으로 공개 승인하지 않습니다. 정원 마감·대기자 접수도 원문에서 확인합니다.
- 접수 종료일에 정확한 종료 시각을 모르면 다시 검토로 돌립니다.
- 검토 기한이 지나거나 수집된 일정/대상/이미지 주소 등의 내용이 바뀌면 다시 검토합니다.
- 원문 전체/첨부 내용 해시는 아직 수집하지 않습니다. 같은 URL의 이미지·첨부 내용 교체는 감지하지 못할 수 있습니다.
- 마지막 성공 수집이 72시간을 넘거나 수집기가 이전 자료로 표시한 공고는 공개를 보류합니다.
- 조회수/수집시각 변화만으로 승인을 없애지는 않습니다.
- 자료 연결 실패를 신규 0건 또는 전체 공고가 없어졌다고 표시하지 않습니다.
- 새 기관/학교 공고의 날짜·대상·신청방법 수집기는 별도 연결이 필요합니다. 현재 본문 데이터 자동 연결은 청소년수련관입니다.
- 보건소 불소도포/스케일링 주제는 생활정보 검토 목록에 남겼습니다. 현재 운영·대상·이용방법을 공식 자료로 확인한 뒤 공개합니다.
- 생활정보의 임시휴관이나 기간이 있는 사업은 해당 시설과 날짜를 확인해야 합니다.

현재 반영

- 요청한 미래 진로설계 특강 완전 제외, 2026 토요체육돌봄교실 추가모집 마감 제외.
- 북파일러는 일반 모집이 아닌 대기자 접수로, 비용은 원문 미표기로 수정.
- 삼척교육문화관 휴관·무인도서반납 안내 추가.
- 청소년수련관 첫 페이지 공고 10건을 GitHub에서 읽어 검토 대상으로 연결.
- 원문 미확인 행사/신청기간 불명/직원 전용 워크숍 등은 검토 전 공개하지 않음.

확인한 범위

공개 판정 규칙 30개 시험과 화면 스크립트/데이터 연결 검사를 수행했습니다.
실제 브라우저 실행파일이 준비되지 않아 화면의 실제 시각·모바일 렌더링은 별도로 확인해야 합니다.
현재 파일을 받았거나 GitHub에 업로드했다는 사실만으로 인터넷에 사이트가 배포되는 것은 아닙니다.
공개 웹주소가 필요하면 GitHub Pages 등 호스팅을 별도로 설정해야 합니다.
